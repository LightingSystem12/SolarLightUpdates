# SolarLight Control

Control and monitor your compatible SolarLight ESP32 solar lighting system from your Android phone.

[**Download the latest APK**](https://github.com/LightingSystem12/SolarLightUpdates/releases/latest/download/SolarLight.apk) · [View all releases](https://github.com/LightingSystem12/SolarLightUpdates/releases)

This repository hosts official SolarLight Control APK downloads and update information. Application source code is maintained separately.

## What the app does

- Switch registered lights and manage lighting schedules.
- Monitor reported solar and battery voltage, current, and device status.
- Receive supported fault notifications.
- Give administrators tools to register devices and manage user access.
- Use supported local controller functions when connected to the controller's Wi-Fi network.

An authorized account and a compatible, configured SolarLight controller are required to use the system. Remote features require internet access. Available readings depend on the sensors installed on your controller. Current-based fault detection indicates possible electrical load problems; it does not directly measure whether a bulb emits light.

## Requirements

- Android 10 or newer.
- An internet connection to download updates and use remote features.
- Permission to install the APK from your browser or file manager when Android requests it.

## Install for the first time

1. Open the **Download the latest APK** link above on your Android phone.
2. Download `SolarLight.apk` and open it from your browser's downloads or file manager.
3. If prompted, open Android Settings and allow installation from that browser or file manager.
4. Return to the APK and tap **Install**.
5. Open **SolarLight Control** and sign in with your authorized account.

The APK installs directly; no Google Play account or purchase is needed. Android will ask for your approval before installation.

## Update an existing installation

**Keep your existing app installed.** Open the latest APK and tap **Update**. Compatible updates use the same package and signing key and preserve existing app data.

If your installed version already includes the updater:

1. Open **SolarLight Control → Settings → Check for updates**.
2. When a newer version is available, tap **Download update**.
3. After the download is verified, tap **Install update**.
4. If prompted, allow SolarLight to install apps, return to the app, and confirm **Update** in Android's installer.

The app also checks periodically when you enter the admin or utility dashboard and may display **Update available**. Downloads use your current Wi-Fi or mobile data connection. Updates require your confirmation; the app does not install them silently.

Older versions without the updater need one manual APK update first. If Settings says **You're up to date**, your installed version is at least as recent as the latest compatible published release.

## Troubleshooting

| Message or problem | What to do |
| --- | --- |
| **App not installed** or a package/signature conflict | Keep the existing app installed and contact your system administrator. The APK may use a different signing key or be older than your installed version. |
| **Install blocked** | Allow installation from the browser/file manager, or from SolarLight for in-app updates, in Android Settings. Device administrator restrictions may prevent installation. |
| **Could not check for updates** | Check your internet connection and try again. You can also use the download link above. |
| Download fails or checksum does not match | Check storage and internet access, then download again. Do not install an APK that fails verification. |
| Download link shows **404** | Open the Releases page and confirm that a published release contains `SolarLight.apk`. Report a missing asset to the administrator. |
| **Connection Error** during sign-in | Confirm that Wi-Fi/mobile data has internet access, let the app finish reconnecting, then retry if the server remains unavailable. |

The in-app updater checks the APK's checksum, package name, version, and signing certificate before offering installation. Android performs its own installation checks as well.

## Help and account access

For account activation, device access, login problems, or update failures, contact the administrator who provided your SolarLight account. Include the installed app version and exact error message. Never share your password, signing keys, or access tokens.
